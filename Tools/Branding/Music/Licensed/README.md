Menu music (DH_Music_Menu1..3): K-pop style instrumentals from ElevenLabs' free pregenerated music library
(https://elevenlabs.io/music/k-pop), listed there as "royalty free with no copyright claimed". Check
https://elevenlabs.io/music-terms before a commercial release.
- Menu1: "Neon Seoul" (high-energy, glossy synths, punchy drums)
- Menu2: "Chrome Fever" (aggressive, industrial percussion)
- Menu3: "Thunder Bloom" (builds to a big electronic payoff)
Replace a track: put a file here, convert it to ../DH_Music_MenuN.wav (ffmpeg loudnorm I=-14), run Tools/Python/import_menu_art.py.
